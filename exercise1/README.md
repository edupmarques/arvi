# Virtual Tour

A simple virtual tour built with **A-Frame**.

## Features

* 360° panoramic environments.
* Interactive portals to switch between scenes.
* Animated transitions between locations.
* Interactive hover effects.
* Information panels for each location.
* Mouse and VR controller interaction.

## How to Run

1. Download or clone the project.
2. Make sure the `images` folder contains the required images.
3. Open the project using a local web server.
4. Open the page in your browser.
